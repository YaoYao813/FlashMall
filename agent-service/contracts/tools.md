# 工具契约

> 先写契约，再实现两端。Java 接口与 Python 工具都以本文件为准。
> 契约改动必须同时改 Java 与 Python，并在同一提交里完成。

## 契约字段

- **工具名**：给模型看的函数名，动宾结构，不超过 4 个词
- **description**：给模型看的说明，写清「什么时候该调 / 什么时候不该调」
- **参数**：JSON Schema，每个字段有类型、必填性、取值范围
- **Java 接口**：方法 + 路径 + 请求体
- **返回体**：成功与失败的结构（注意本项目的错误是 `HTTP 200 + body.code != 200`）
- **错误码映射**：业务错误码 → 工具返回给模型的说法
- **写操作**：是 / 否
- **幂等键**：写操作必填，写明取哪个字段
- **人工确认**：写操作必须为「是」，并写明确认卡展示什么
- **审计字段**：谁、何时、什么参数、结果、是否被批准

## 示例（模板，实现时替换）

### `query_seckill_events`

- **description**：查询秒杀活动列表，用于回答「现在有哪些活动 / 某活动状态如何」。不要用它做数据统计。
- **参数**

```json
{
  "type": "object",
  "properties": {
    "status": { "type": "string", "enum": ["pending", "running", "ended"] },
    "page": { "type": "integer", "minimum": 1, "default": 1 }
  },
  "required": []
}
```

- **Java 接口**：`GET /api/admin/seckill/events?status&page`（待实现）
- **返回体**：`{ "code": 200, "data": { "records": [...], "total": n } }`
- **错误码映射**：`code=401` → 「未登录或登录过期」；`code=500` → 「服务异常，稍后重试」
- **写操作**：否
- **幂等键**：—
- **人工确认**：否
- **审计字段**：调用人、时间、参数、返回条数
