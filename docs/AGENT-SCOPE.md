## 四、明确不做（及一句话答法）

| 不做 | 答法 |
|---|---|
| Multi-Agent 协作 | 单 Agent 已能覆盖场景，多 Agent 在没有真实分工需求时是纯负担 |
| 长期记忆 / Memory 分层 | 秒杀运营是任务型场景，跨会话记忆没有真实需求，做出来是假的 |
| 前端从零写 | 用现成 Chat UI，面试官关心架构不是像素 |
| Prometheus / Loki 全家桶 | 排障子图用现有 Redis / MQ / DB 指标足够，先补可观测体系会挤掉主线 |
| 真实支付 / 物流对接 | mock 足够，业务真相源是 Java 侧 |
| Agent 进秒杀主链路 | 延迟不可控，旁路才安全 |
